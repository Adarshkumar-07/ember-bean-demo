# Ember & Bean — Portfolio Concept

A custom React/Vite café website concept for a fictional Portland neighborhood café.

## Visual direction
Warm parchment, olive, rust, honey and clay tones with editorial typography and handcrafted CSS illustrations. This intentionally uses a different visual language from the Apex Roofing demo.

## Run locally
npm install
npm run dev

## Build
npm run build

Ember & Bean is a fictional concept project. Address, phone number, reviews and business information are placeholders for portfolio/demo use.
